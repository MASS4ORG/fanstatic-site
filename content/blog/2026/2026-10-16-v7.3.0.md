Until now, `ref` and `relref` were the only shortcodes Fanstatic understood. v7.3.0 opens the door: any Liquid file in `shortcodes/` becomes a shortcode you can call from your content, with the same syntax as Hugo.

## Your own shortcodes

Save `shortcodes/audio.html` in your site or theme:

```liquid
<audio controls preload="auto" src="{{ src }}" title="{{ page.Title }}"></audio>
```

and call it from any page:

```md
{{</* audio src="/audio/intro.mp3" */>}}
```

Both Hugo notations work: `{{</* … */>}}` inserts HTML without a stray `<p>`, and `{{%/* … */%}}` inserts Markdown that is rendered with the page. Shortcodes nest, receive typed arguments, and see `inner`, `page` and a `shortcode` object with the call's name, parameters, parent and position. A site file overrides the theme's, and `audio.pt-br.html` or `audio.rss.xml` take over for Portuguese pages or the RSS feed. A typo in a shortcode name fails the build with the file, line and column.

## Beyond Hugo

- **Parameter schemas**: a YAML header in the shortcode declares types, required parameters, defaults and allowed values, and every call is checked at build time.
- **Lists and maps**: `tags=["a", "b"]` and `size={w: 300, h: 200}` arrive as real collections.
- **Directives**: `:::note{kind=warn} Title` … `:::` calls the `note` shortcode, as in Docusaurus.
- **Layouts**: `{% shortcode 'audio', src: page.Params.audio %}` calls the same shortcode from a template, and `page.Shortcodes` tells a layout which assets a page needs.

## Built-in shortcodes

`details`, `figure`, `highlight`, `instagram`, `param`, `qr`, `vimeo`, `x` and `youtube` ship with Fanstatic, next to `ref` and `relref`. YouTube embeds use the privacy-enhanced host, QR codes are inlined as PNGs, and a site or theme file of the same name replaces any of them. See the [shortcodes guide](/docs/content/shortcodes) for every argument.

## Branch bundles are list pages

An `_index.md` file now renders as a list page with `list.html` and gets an RSS feed, as in Hugo, while `index.md` stays a single page.
